# Pet Projects

A collection of my personal experiments, side projects, prototypes, and random ideas that I wanted to build or explore.

This repository is my personal playground for trying out new technologies, learning by building, testing ideas, and occasionally turning a small experiment into something more useful. Some projects may be polished and practical, while others may simply exist because I was curious about how something worked.

## What You'll Find Here

The projects in this repository can cover a pretty wide range of topics, including:

* 🤖 **AI & Machine Learning** — experiments with AI tools, models, APIs, and automation
* 📊 **Data & Analytics** — data analysis, visualization, data processing, and small data projects
* 🛠️ **Developer Tools** — utilities, scripts, and tools that solve small problems
* 🌐 **Web & Software** — small applications, prototypes, and experiments with different technologies
* 🧪 **Experiments** — proof-of-concepts and technical experiments for learning or exploration
* 💡 **Random Ideas** — anything interesting enough that I wanted to build it

## Why This Exists

I learn a lot by actually building things. Rather than letting small ideas, experiments, and half-finished projects disappear into random folders on my computer, this repository gives them a home.

Not every project here is intended to become a finished product. Some are experiments to answer a question, some are attempts to learn a technology, and some are simply ideas that seemed fun to build.

## Project Structure

Each project generally lives in its own directory and is intended to be reasonably self-contained.

```text
pet-projects/
├── project-1/
│   ├── README.md
│   └── ...
├── project-2/
│   ├── README.md
│   └── ...
└── ...
```

Individual projects may have their own README with details about:

* What the project does
* Why I built it
* Technologies used
* How to run it
* Things I learned
* Known limitations
* Ideas for future improvements

## A Work in Progress

This repository will probably never be "finished."

Projects may be added, abandoned, revisited, rewritten, or completely replaced as I learn new things and come up with new ideas. Some experiments might be rough around the edges, and that's part of the point.

The goal isn't to make everything perfect — it's to **build, experiment, learn, and keep a record of the process**.
